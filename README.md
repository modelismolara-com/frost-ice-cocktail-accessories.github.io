# FROST — Ice & Cocktail Accessories 🧊

> **Premium ice tools, cocktail accessories, bar essentials, and cold-drink lifestyle products.**

FROST is a modern lifestyle storefront concept focused on the art of chilled drinks, refined home entertaining, cocktail preparation, and premium ice presentation.

The brand combines **crystal-clear ice aesthetics, dark surfaces, cool metallic details, and sophisticated barware** to create an experience that feels contemporary, elegant, and distinctive.

---

## 🧊 Brand Philosophy

FROST is built around a simple idea:

> **Cold drinks deserve beautiful details.**

From the first cube to the final garnish, the experience of preparing and serving a drink can be part of the occasion.

FROST brings together practical cocktail tools and visually refined accessories for:

- Home bars
- Cocktail enthusiasts
- Entertaining
- Gift collections
- Cold-drink rituals
- Modern kitchen spaces
- Weekend gatherings
- Professional-inspired home setups

The goal is not simply to sell bar accessories, but to create a recognizable **cold-drink lifestyle identity**.

## 🧊 Signature Experience

FROST should make the product photography feel almost tactile.

Images should emphasize:

- Transparent ice
- Condensation
- Reflections
- Glass textures
- Stainless steel
- Dark stone
- Citrus
- Fresh herbs
- Cocktail surfaces
- Controlled studio lighting

Photography should be:

- Realistic
- Clean
- High resolution
- Professionally framed
- Product-focused
- Free from website UI
- Free from unnecessary text
- Free from prices or buttons inside the images

Each product should ideally have its **own distinctive image** rather than repeatedly reusing the same photograph.

## 🌐 GitHub Pages

FROST is designed to work as a static GitHub Pages project.

Recommended deployment:

1. Create the public GitHub repository.
2. Upload the project files.
3. Keep the provided `.nojekyll` file.
4. Open repository **Settings**.
5. Select **Pages**.
6. Choose the deployment branch.
7. Save the configuration.
8. Wait for GitHub Pages to publish the site.

No server-side runtime is required for the basic storefront.
